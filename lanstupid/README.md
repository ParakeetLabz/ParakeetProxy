# LanStupid

A pure Scramjet proxy. Every engine file (Scramjet + epoxy transport) loads from cdn.jsdelivr.net.

Served by jsDelivr from this repo:

- App: https://cdn.jsdelivr.net/gh/ParakeetLabz/ParakeetProxy@main/lanstupid/index.html
- Worker: https://cdn.jsdelivr.net/gh/ParakeetLabz/ParakeetProxy@main/lanstupid/lanstupid-sw.js

Full working copy (its own origin, so the service worker can run): https://lanstupid-zteam4.vercel.app/I/X/L
